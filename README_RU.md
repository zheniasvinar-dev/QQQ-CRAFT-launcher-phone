## 🔨 Сборка

```bash
git clone https://github.com/zheniasvinar-dev/QQQ-CRAFT-launcher-phone.git
cd QQQ-CRAFT-launcher-phone
git submodule update --init --recursive
./gradlew assembleFullDebug
```
